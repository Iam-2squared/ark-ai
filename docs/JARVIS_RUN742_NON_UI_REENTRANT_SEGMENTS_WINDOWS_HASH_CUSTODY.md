This rejects even equal-valued replacement after the original custody snapshot. Nine authored new tests include a valid deny-only result, seven parameterized reflected-mutation cases, and an additional guarded callback case. The caller-retained anchors and tips remain **untrusted**, not independently authenticated.
- **B: Windows lexical hash boundary**: [source commit `29e0439`](https://github.com/Iam-2squared/ark-ai/commit/29e04393750e616e80fb6d0375af578e8b7516b0), [four regression cases `9c40043`](https://github.com/Iam-2squared/ark-ai/commit/9c400435823843c98a1cf4c6d769f6e26c7bd420). The lexical checker now pins both the original `hashlib` module identity and its own digest helper before the caller's synthetic path is read by hashing code. Tests cover ordinary deny-only output, replaced digest helper, same-hash-function substitute module and fake hash function; no substituted callback may receive the label. **No filesystem read, Windows handle, SQLite write, real path guarantee, or tool execution** is added.
